键位编辑器用来把键位放到游戏的按钮上。它在投屏窗口里打开，下面就是正在运行的游戏画面。

![键位编辑器](figure:editor-overview)

| 区域 | 说明 |
|---|---|
| 顶栏 | 方案名称、是否已保存，以及“撤销”、“重做”、“更多”、“保存”和“完成”按钮。 |
| 画面 | 正在运行的游戏，键位就放在上面。 |
| 侧边栏 | “组件库”和“已放的”两个页签；选中一个组件时显示它的属性。 |

## 打开编辑器

- 在投屏窗口的工具栏上打开“键位选项”，选“编辑键位”。需要先选用一个方案，可以在同一个菜单里选。
- 也可以在新建方案时点“创建并编辑”，详见[方案与分享](help:profiles)。

## 添加键位

1. **打开“组件库”页签**：在侧边栏里；每个组件名字下面有一句说明，指针停在上面会多说一句用在哪；“搜索组件”可以按名称或说明查找。
2. **把组件拖到游戏的按钮上**：也可以选中一个组件后按 <kbd>Enter</kbd>，把它放在画面中间。
3. **按一个键**：键盘上的键、鼠标键或滚轮都行。点“跳过”可以以后再设。

![添加键位](figure:editor-components,editor-drag!,editor-capture)

有这些组件，一个组件只做一件事：

| 分组 | 组件 | 作用 |
|---|---|---|
| 基础 | 点击 | 每按一次键点一下屏幕，按多久都只点一下。 |
| | 按住 | 键按多久，屏幕上就按住多久。 |
| | 长按 | 每按一次键，屏幕按住设定的时长。 |
| | 连发 | 按住键时按设定的频率一下一下地点。 |
| | 滑动 | 每按一次键沿你画的路线划一次。 |
| | 双指缩放 | 两个键分别张开、捏合两根手指。 |
| 移动 | WASD 轮盘 | W、A、S、D 推屏幕上的摇杆，另有走路键和冲刺键。 |
| | 右键行走 | 点哪里，英雄就朝哪里走。 |
| | 手柄摇杆 | 手柄的摇杆推屏幕上的摇杆。 |
| 视角 | 视角 | 按锁定键后，移动鼠标就转视角。 |
| | 手柄视角 | 手柄右摇杆转视角。 |
| | 自由视角 | 按住键时用鼠标四处看，人物不转身。 |
| MOBA | 技能施法 | 按下朝光标瞄准，松开或点击施放。 |

手机的返回键、打字、截图、切换方案等不在组件库里，在逻辑里用系统节点做，详见[脚本](help:scripts)。

### 示例组件与我的组件

组件库最后两组是用蓝图做的组件，拖到画面上的用法和上面的一样：

| 分组 | 组件 | 作用 |
|---|---|---|
| 示例组件 | 按住切换 | 按一下按住，再按一下松开。 |
| | 双击 | 按一下点两下，间隔可以调。 |
| | 连击 | 按一下连点几下，次数和间隔可以调。 |
| | 依次点击 | 每按一下点下一处，几处轮流点。 |
| | 按住显示全部键位 | 按住它的键时，所有键位提示完整显示，提示关着也显示；松开恢复原样。刚放下时还没有键，要给它按一个。 |
| 我的组件 | 你自己做的 | 最后一块“新建组件…”：起个名字，就做好一个能用的组件（一个按键，按下时点一下它摆的位置），并打开它的逻辑让你改。 |

- **示例组件只能看**：双击打开“编辑组件”窗口，看它是怎么做的；想改就点右边的“复制到我的组件”，改的是你自己的那一份。
- **我的组件共用一份**：组件存在组件库里，用到它的方案都引用同一个，改了它，这些方案一起变；保存组件代码时，正在投屏、用到它的方案马上重新加载逻辑。“编辑组件”窗口右边可以改名字、一句说明（组件库里显示）、图标和分类，下面列出用到它的方案。
- **画面上**：和其他组件一样是圆标，里面是它的图标和第一个按键；它还有别的位置时（如“依次点击”的第二处、第三处），那几处各有一个小点，用虚线连起来，选中它时可以拖动这些小点。双击圆标上的键同样是重新按一个键。
- **属性**：按组件里声明的属性显示——按键、数字、文字、开关、另一个组件；顶部的“打开组件”打开它的逻辑。
- **基于**：“新建组件”对话框的“基于”可以选从零开始、13 个本体组件之一或你的另一个组件；选了本体组件，新组件按法和它一样，代码里留好了“按下时再做点什么”的空位。
- **成组的组件**：声明了子组件的组件拖一次就放下整组，组自己一个圆标，子组件各是一个本体组件、各自改键；拖组的圆标整组一起挪，拖某个子组件只挪它，“已放的”里子组件缩在组下面。
- **方案要能有逻辑**：放这两组的组件时，方案会变成带逻辑的文件夹方案；扩展带来的方案不能有逻辑，放不了。
- **导出与导入**：导出方案时，用到的“我的组件”一起打进包里（示例组件不用带）；导入时，和你已有的同名但内容不同的组件会改名为“名字 2”，两份都留，导入的方案用它，你原来的方案照旧。

## 移动和排列键位

- 点一个键位就能选中它。按住 <kbd>Ctrl</kbd> 或 <kbd>Shift</kbd> 再点可以多选；在空白处拖动可以框选。按 <kbd>Esc</kbd> 取消选择。
- 拖动键位可以移动它。键位会吸附到其他键位和中线；拖动时按住 <kbd>Alt</kbd> 可以自由摆放，也可以关掉“吸附到其他键位与中线”。
- 方向键可以微调选中的键位，按住 <kbd>Shift</kbd> 移动得更多。
- 在画面上双击键位上的按键标签，可以给它重新按一个键。
- 选中两个或更多键位时，侧边会显示“对齐”和“分布”。
- “冻结画面”会让画面停住，方便给一闪而过的按钮放键位。
- 用缩放按钮，或按住 <kbd>Ctrl</kbd> 转动滚轮来缩放。点百分比可以恢复适应画面。

## 修改键位

选中一个组件，侧边就会显示它的属性，从上到下一列：

- **名称**：在最上面，下面一行是组件类型和它做什么。“更多”（…）里有“重命名”、“复制一份”（在旁边放一个一样的）、“复制”和“粘贴到画面中间”、“设为新组件的默认值”、“恢复出厂默认”和“删除”。在画面上选中组件按 Ctrl+C 复制，再按 Ctrl+V 粘贴到鼠标所在的地方（鼠标不在画面上时粘贴到中间）；复制的组件在程序关掉之前一直留着，换一台手机的编辑器里也能粘贴，键和设置照原样带过去。
- **按键**：这个组件用哪些键；点一下按键框再按一个键就换上。绑的是鼠标键时，下面还能选“什么时候生效”。
- **位置**和这种组件自己的设置，比如长按的时长、连发的频率、视角的灵敏度。**锚点**是组件"认准"的那个角或边：换了屏幕大小或比例（换一台手机、平板）时，组件离这个角或边的距离保持不变，和游戏自己的按钮一样。选游戏按钮所在的那一侧，比如右下角的技能键选"右下"；在画面上拖动组件时会自动选最近的那个。WASD 轮盘绑了冲刺键时，"冲刺时推多远"决定按住冲刺键时手指推到半径的几倍，画面上那圈虚线就是它，拖虚线上的点也能改。
- **开始时打开**：关掉时，方案加载后这个组件先不生效，要由逻辑来打开。
- **代码名**：在“名称”下面，是逻辑里用的名字，写成 `controls.fire`。新组件的代码名跟着按键走：F 键上的按住叫 `holdF`，鼠标左键上的叫 `holdMouseLeft`，重名时后面加 `2`。改键时代码名和逻辑里用到它的地方一起改。在框里输入可以自己起名；从这以后代码名就不再跟着键变了。只能用英文字母、数字、`_` 和 `-`，要以字母开头，不能和别的组件或变量重名；改一次只算一步撤销。
- **生效条件**：总是，或某个变量开着 / 关着时才生效。
- **附加**：扩展提供的附加功能会出现在这里。想让所有键位都用上（比如随机落点），到"扩展"页这个扩展的"设置"里打开，一次就对所有方案生效；这里会显示"全局"的几项，某个键位不想要就把它的开关关掉。
- **在蓝图里能用**：这个组件在逻辑里能用的事件（红色）和函数（蓝色）；点“在蓝图里引用它”会打开这个组件自己的蓝图页，不在代码里加任何东西。
- **交给逻辑的键**：逻辑接了这个组件的按下 / 松开 / 按住事件时，键帽右上角有一个“逻辑”小标记，属性面板里写着“按 F 只运行逻辑”：按这个键组件自己不再按屏幕，由逻辑决定什么时候按。要它照常先按，在蓝图的事件方块上把“按这个键时”改成“照常按下，再运行逻辑”。

没填按键的组件在画面上画成虚线圆标、写着它的名字，只给逻辑用。“已放的”页签会列出所有组件，以及各自绑定的键。

## 冲突

两个键位用了同一个键时，顶部会显示有几处冲突。点击它会选中冲突的键位，再给其中一个换个键就行。

![两个键位都用了 Q 键：顶部显示冲突，两个键位都标成红色。](figure:editor-conflict)

## 删除键位

“更多”里的“删除”（或按 <kbd>Delete</kbd>）会删掉选中的组件。逻辑里用到它时，会先弹一个对话框，有三个选择：

| 选择 | 结果 |
|---|---|
| 连这些方块一起删 | 组件删掉，逻辑里用到它的语句也一起删掉，算同一步撤销。 |
| 只删组件 | 只删组件；用到它的方块留在逻辑里。 |
| 取消 | 什么都不变。 |

找不到组件的方块画成红色描边、带警告标记，上面写着“找不到组件「…」：已被删除”；蓝图上方还有一条提示，说明有几个这样的方块。每个这样的方块上有两个按钮：“换成别的组件…”把它改成用你选的那个组件，“删除方块”把它从逻辑里拿掉。按 <kbd>Ctrl</kbd>+<kbd>Z</kbd> 可以撤回删除或这次修改。

## 画面与逻辑

顶栏中间的“画面 / 逻辑”切换编辑器的两个视图：“画面”摆组件、改属性；“逻辑”写这个方案的代码（见[脚本入门](help:scripts)）。切到逻辑时窗口太小会自动放大，切回画面时还原。“保存”和“完成”同时管方案和代码。

## 试玩

点顶栏的“试玩”（烧瓶图标），不用离开编辑器，就能直接在游戏里试这些键位；按钮亮着表示正在试玩，再点一次回到编辑。在逻辑视图里点它会先回到画面。

![试玩时画面不再变暗，键位像平时一样生效。](figure:editor-try)

## 预览其他屏幕

“预览的屏幕比例”可以看看键位在其他比例的手机上（比如 20:9 或 21:9）是什么样子。这只是预览；切回手机自己的比例才能编辑。

## 保存

- **保存**：保存改动，包括逻辑里改过的代码文件。“完成”会保存并关闭编辑器。
- **另存为**：“更多 > 另存为…”把改动存成一个新方案，然后接着编辑新方案；原来的方案保持上次保存时的样子。
- **放弃**：“更多 > 放弃改动并退出”不保存，直接关闭编辑器。
- **来自扩展的方案**：你的改动会单独保存，“更多 > 还原原版…”可以删掉这些改动。

关闭投屏窗口时，如果还有没保存的改动（方案或代码），GameScrcpy 会问你要不要保存。

## AI 的草稿

通过 MCP 连上的 AI 客户端改了方案时，改动先放在它自己的草稿里。方案页上这张方案卡片会多出一个按钮，比如“Claude 的草稿”：点开就在这个编辑器里看草稿，什么都还没生效。

这时的编辑器只读。顶部一条会说这是谁的草稿，旁边有“应用”“丢弃”“关闭”。画面上的键位：草稿新增的用绿框，改过的用橙框，删掉的用红框画在它原来的位置（颜色淡一些）。侧栏列出改动的键位，逻辑视图给改动过的方块描边并列出被删的方块，代码视图把改动过的文件按逐行差异显示。“应用”让草稿成为正式方案（你点这一下就是确认），“丢弃”扔掉草稿，“关闭”退出预览、草稿留着以后再看。

## 编辑器快捷键

| 按键 | 作用 |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | 撤销上一步编辑 |
| <kbd>Ctrl</kbd>+<kbd>Y</kbd> | 重做编辑 |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | 保存方案 |
| <kbd>Ctrl</kbd>+<kbd>D</kbd> | 复制选中的键位 |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | 全选键位 |
| <kbd>Delete</kbd> | 删除选中的键位 |

可以在“设置 > 快捷键”里修改这些按键。
