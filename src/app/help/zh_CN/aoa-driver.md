AOA 让手机把 GameScrcpy 当成接在数据线上的一块触摸屏，外加一个鼠标和一个键盘。手机不打开 USB 调试也能用。在 Windows 上，要先给手机装一次 WinUSB 驱动，下面用免费的 Zadig 来装。

## 用 Zadig 安装 WinUSB 驱动 {只需做一次}

1. **下载并打开 Zadig**：从 [Zadig 官网](https://zadig.akeo.ie) 下载，双击就能打开，不用安装。Windows 问是否允许更改时点“是”：装驱动的是 Zadig，GameScrcpy 自己不需要管理员权限。
2. **列出全部设备**：用数据线把手机连到电脑，在 Zadig 的菜单里选 Options > List All Devices。
3. **选中你的手机**：在下拉列表里选手机的名字，通常带着“(Interface 0)”或“MTP”。不要选“ADB Interface”，那是 USB 调试用的。
4. **换成 WinUSB**：确认绿色箭头右边是 WinUSB，点 Replace Driver（第一次装时叫 Install Driver），等它提示装好。
5. **回到 GameScrcpy**：不用重启，它会自己认出来并提示“驱动已装好”，手机卡片上的连接方式写着“USB · AOA”。

![用 Zadig 安装 WinUSB 驱动](figure:zadig-open,zadig-list,zadig-pick,zadig-install!,driver-done)

> [!WARNING]
> **装好之后**：在 Windows 上，这台手机用 AOA 时就不能同时用 USB 调试，在资源管理器里传文件也可能不行了。想换回去：打开设备管理器，右键这台手机，选“卸载设备”并勾选“尝试删除此设备的驱动程序”，再重新插一次手机。

## 选 AOA

在“设置 > 输入与键位 > 触控”里把触控方式选成 AOA，也可以只给某一台手机选。选的时候会列出没有画面时不能用的功能，确认后才生效，下次连接这台手机时开始用。

## 有画面，或者没有画面

- **开了无线调试**：画面走无线，触控走数据线上的 AOA。手机卡片上写着“无线 · 画面 + USB · AOA 触控”。
- **没开无线调试**：打开的是“控制窗口”，一块手机屏幕比例的深色画布，上面画着键位提示，写着“无画面 · 看着手机操作”。控制窗口在最前面时，键盘和鼠标才会变成触控。
- **手机上的鼠标指针**：没有画面时手机上会出现一个鼠标指针，光标状态下看着手机屏幕点；锁定视角时不再移动指针，手机会把它藏起来。
- **手机怎么拿**：没有 adb 就不知道手机是竖着还是横着。在控制窗口工具栏的“手机怎么拿”里选竖屏、横屏（向左）或横屏（向右），默认按方案记的方向，每台手机会记住上次选的。

## 扫码连接 GameScrcpy 伴侣

没有 USB 调试时，手机上的 GameScrcpy 伴侣经 Wi-Fi 连这台电脑。连上后，键位提示也画在手机屏幕上，手机弹出输入框时可以直接用电脑键盘打字，中文也行。

1. **同一个 Wi-Fi**：电脑和手机要连在同一个 Wi-Fi 或局域网里。
2. **装上伴侣**：手机上还没有 GameScrcpy 伴侣时，用手机自带的相机或扫一扫扫控制窗口里的二维码，会打开这台电脑上的下载页；下载安装，手机问是否允许安装来自这个来源的应用时点允许。
3. **扫码连接**：在手机上打开 GameScrcpy 伴侣，点“扫码连接”，允许使用相机，扫控制窗口里的二维码。连上后二维码就会消失。
4. **用电脑键盘打字**：在伴侣的 **权限** 页，“输入法”一行点 **去打开**，打开“GameScrcpy 伴侣”的开关，回来再点 **选择** 选中它。手机弹出输入框时，屏幕底部会出现一条细提示“正在用电脑键盘打字”，点它可以换回手机键盘；在伴侣的 **功能** 页可以把这条提示放到顶部。

> [!TIP]
> **下次**：双方会记住对方。在同一个 Wi-Fi 下，只要打开控制窗口，伴侣就会自己连上，不用再扫码（伴侣的“自动连接”默认开着）。

伴侣的其他功能、开关和权限：[GameScrcpy 伴侣](help:companion)

> [!WARNING]
> **Windows 防火墙**：第一次会问是否允许 GameScrcpy 接受来自网络的连接。请允许专用网络，否则手机连不上。GameScrcpy 只在控制窗口显示二维码、或在等配对过的手机时才监听。

## 没有画面时不能用的

识图与识图工作台、逻辑和脚本里的 `vision.*`（只会得到 null、[] 或 false）、录像、剪贴板同步、启动应用、延迟测试，以及声音、息屏与旋转。键位、锁定视角、编辑键位和逻辑里的触控都照常能用。
