GameScrcpy 伴侣是装在手机上的小应用，和电脑上的 GameScrcpy 一起用：在手机屏幕上显示电脑的光标和键位提示，让你用电脑键盘往手机里打字（中文也行），没有 USB 调试时也能经 Wi-Fi 连上电脑。不装它也能投屏、用键位，它只管这几件事。

## 它能做什么 {#features}

- :mouse-pointer-click: **手机上的光标**：鼠标在电脑上的投屏画面里时，手机屏幕上也显示它指在哪里。
- :keyboard: **键位提示**：像投屏窗口里一样，在手机的游戏画面上画出当前方案的键位。没有画面时（例如经 AOA）会自己显示。
- :type: **电脑键盘输入**：投屏时，在电脑上打的字（包括中文）经 GameScrcpy 伴侣输入法进入手机的输入框。
- :wifi: **自动连接**：在同一个 Wi-Fi 下，手机会自己连上扫码配对过的电脑，连接断开后也会再连。

## 装上伴侣 {#install}

经 USB 调试投屏时不用自己去找安装包。第一次打开上面的某项功能时，投屏窗口会提示“要在手机上显示光标，需要在手机上安装 GameScrcpy 伴侣”这样的话，点 **安装**，手机上弹出询问时允许。以后 GameScrcpy 带来新版本的伴侣，会自己替换手机上的旧版本。

没有 USB 调试时（比如经 AOA 或触控盒控制手机），扫控制窗口里的二维码下载安装：[AOA 触控与 WinUSB 驱动](help:aoa-driver)

## 两边都能开关 {#switches}

这四个开关和键位提示的不透明度，是这台手机在 GameScrcpy 里的设置。在电脑上改、在手机上改都行，改了一边，另一边跟着变。

- **在电脑上**：**设置 > 输入与键位 > 手机上的 GameScrcpy 伴侣** 里有“用电脑键盘打字”、“在手机上显示键位提示”和它的不透明度、“在手机上显示光标”、“经 Wi-Fi 自动重新连接”。连着手机时选这台手机，就只改它一台；手机上改的也记在这台手机名下。
- **在手机上**：伴侣 **首页** 的“快捷开关”，或 **功能** 页每张卡片上的开关。

手机没连电脑时改的开关会写着“连上电脑后发过去”，连上就同步。电脑上的 GameScrcpy 版本较旧时，手机上改的先记着，等连上能接收的版本再发过去。

> [!NOTE]
> **只在手机上的选项**：光标的“大小”和“样式”，以及打字时那条提示放在“底部”还是“顶部”（“提示条”），只存在这台手机上，不会同步到电脑。

## 键位提示的不透明度 {#opacity}

手机上的键位提示先完整显示，过一会儿淡到你设的不透明度。电脑上在 **手机上键位提示的不透明度** 里调，手机上在 **功能 > 键位提示 > 淡化后的不透明度** 里调，两边是同一个值。投屏窗口里的键位提示另有自己的不透明度，在 **设置 > 输入与键位 > 键位提示** 里。

## 经 Wi-Fi 连接 {#wifi}

1. **扫码配对**：在伴侣首页点 **扫码连接**，扫 GameScrcpy 控制窗口里的二维码。只有第一次要扫。
2. **自己重连**：“自动连接”开着时（默认开着），在同一个 Wi-Fi 下，伴侣会自己找到配对过的电脑并连上，断开后也会再连。
3. **管理电脑**：伴侣的 **电脑** 页列出这台手机连过的电脑。**现在连接** 马上再试一次；**删除** 让手机忘掉这台电脑和它发来的设置，以后要经 Wi-Fi 连接，得重新扫码。

连不上时，看看电脑和手机是不是在同一个 Wi-Fi，以及 Windows 防火墙是否允许了 GameScrcpy。

## 伴侣要的权限 {#permissions}

伴侣的 **权限** 页写着每项权限的用途和现在的状态，缺了的点 **去打开**。

| 权限 | 用来做什么 |
|---|---|
| 悬浮窗 | 在游戏上显示光标与键位提示。 |
| 通知 | 显示伴侣已连接，需要时随手停止。 |
| 相机 | 只用来扫 GameScrcpy 控制窗口里的二维码。 |
| 输入法 | 让电脑往手机里打字。经 USB 调试时 GameScrcpy 会自己启用并选中它；没有 USB 调试时，在这里启用一次，再点 **选择** 选中它。 |
| 录屏（截图） | 电脑要截图时，安卓会请你允许录屏。 |

> [!TIP]
> **隐私**：伴侣只和你自己电脑上的 GameScrcpy 通信（经 USB 调试或你的 Wi-Fi），不收集、也不向别处发送任何数据。
