# GameScrcpy ESP32 触控盒固件

把一块 ESP32 开发板变成手机的“外接触摸屏 + 键盘 + 鼠标 + 手柄”。电脑上的 GameScrcpy 经串口（或 Wi-Fi）把触控发给板子，板子再以 USB 或蓝牙的硬件设备身份送进手机，手机不需要打开 USB 调试。协议见 `protocol/esp32/SPEC.md`。

## 支持的芯片

| 芯片 | 怎么连手机 | 怎么连电脑 | Wi-Fi |
|---|---|---|---|
| ESP32-S3 | 原生 USB 口插手机（USB 触摸屏） | 板上 USB 转串口的那个口 | 有 |
| ESP32-S2 | 原生 USB 口插手机（USB 触摸屏） | 板上 USB 转串口的那个口，或外接 USB 转串口模块 | 有 |
| ESP32-P4 | 高速 USB（USB 2.0 OTG HS）口插手机，轮询 125 微秒 | USB 转串口的口，或芯片自带的 USB 串口（全速口） | 没有，只能串口 |
| ESP32（经典） | 蓝牙 HID，手机上配对一次 | 板上 USB 转串口的口 | 有 |
| ESP32-C3 | 蓝牙 HID，手机上配对一次 | USB 转串口的口，或芯片自带的 USB 串口 | 有 |
| ESP32-C6 | 蓝牙 HID，手机上配对一次 | USB 转串口的口，或芯片自带的 USB 串口 | 有 |

板子至少要有 4 MB 闪存（常见开发板都满足）。

## 哪个口接手机，哪个口接电脑

- **ESP32-S3-DevKitC-1 一类有两个 USB 口的板子**：标着“USB”的口（原生 USB，GPIO19 / GPIO20）用 OTG 线接手机；标着“UART”或“COM”的口（CP210x / CH34x 转串口）接电脑。
- **ESP32-S2 板子**：原生 USB 口接手机；电脑接板上的转串口口。只有一个原生 USB 口的小板（如 S2 Mini）要在 GPIO43（TX）/ GPIO44（RX）上外接一个 USB 转串口模块接电脑。
- **ESP32-P4 开发板**：“USB 2.0 OTG HS”口接手机，“UART”口（或标着 USB-Serial-JTAG 的全速口）接电脑。
- **经典 ESP32、C3、C6**：只用一根线接电脑；手机经蓝牙连接。第一次在手机的蓝牙设置里找到“GameScrcpy XXXX”并配对，之后开机自动回连。

电脑上不需要装驱动：CH34x、CP210x 与芯片自带的 USB 串口在 Windows 10 / 11 上都自带驱动。

## 扮演的设备

- 触摸屏：最多 10 指，坐标 0～32767，带触点数与“最多触点数”特性报告。
- 键盘与消费类按键：返回、主页、最近任务、音量，以及打字。手机接了硬件键盘时，Android 默认不弹出屏幕上的输入法；需要时在手机的“物理键盘”设置里打开“显示虚拟键盘”。
- 鼠标：相对移动、5 个按键、滚轮。光标状态下手机自己画出鼠标指针。
- 手柄：32 个按键、方向键、两个摇杆、两个扳机，没有震动。

电脑 2 秒没有发来任何帧时，板子会抬起所有手指、松开所有按键、手柄回中，手指不会卡在手机上。

## 开机顺序与各部分状态

板子上电后先把串口协议起起来、立刻应答电脑的 HELLO，然后才启动手机那头的 HID（USB 或蓝牙）与 Wi-Fi。任何一部分启动失败（USB / TinyUSB 装不上、蓝牙初始化失败、Wi-Fi 初始化失败）都只记一条日志、把那一部分标成“did not start”，板子继续运行、照样应答电脑，不会因为某一部分失败而反复重启。

HELLO 的最后一段带各部分的状态（USB 到手机、蓝牙、Wi-Fi 各自“已就绪 / 还没启动 / 这块芯片没有”），协议见 `protocol/esp32/SPEC.md` 第 3.2 节。旧程序不认识这一段会忽略它，照样能握手；旧固件的 HELLO 没有这一段，新程序按“不知道”处理。第一封 HELLO 在 USB / Wi-Fi 起好之前就发出（标“还在启动”），起完后再发一封带结果的。

## 刷写

一般在 GameScrcpy 里刷：扩展页打开 ESP32 扩展后点卡片底部的“设置”（设备页开发板卡片上的“设置”是同一个窗口），在“固件”一组点“刷写固件…”，选板子接电脑的那个串口。程序自带固件和刷写工具，会自己让板子进入下载模式。

**什么时候按 BOOT**：程序提示“没有进入下载模式”时，按住板上的 BOOT 键（有的板子标 IO0 或 B），同时插上数据线（或按一下 RST / EN 再松开），然后松开 BOOT，在程序里再点一次刷写。

自己编译：装好 ESP-IDF v6.1 后运行 `tools/build_esp32_firmware.ps1`（按 `-IdfPath`、环境变量 `IDF_PATH`、再到 `GS_IDF_ROOT`（缺省 `C:\Espressif`）下的常见位置找 ESP-IDF；工具链装在那个根目录的 `tools` 下时脚本会自动设好 `IDF_TOOLS_PATH`），它编译六个型号，把每个型号合并成从 0 地址开始的一个镜像，写进 `release/`，并更新 `release/firmware.json`（版本、每个型号的文件、SHA-256、闪存大小、芯片编号）。固件版本写在 `version.txt`。

## Wi-Fi

板子接在串口上时，在 ESP32 的设置窗口里点“设置 Wi-Fi…”，填网络名和密码。程序同时生成一个只有这台电脑和这块板子知道的密钥，之后经 Wi-Fi 收发的每一帧都带这个密钥算出的标签，别人发来的会被丢掉。板子在局域网里用 mDNS 服务 `_gs-esp32._udp` 报出自己，程序能自动找到它。

## USB 编号

USB 设备的厂商编号用乐鑫的 0x303A，产品编号 0x40A5 只是占位，正式发布前要向乐鑫申请一个（见 `main/gs_hid_usb.c` 与 `main/gs_hid_ble.c` 里的 `GS_USB_PID`、`GS_BLE_PID`）。
